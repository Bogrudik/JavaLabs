# JavaLabs

Лабораторні роботи з дисципліни «Основи програмування в середовищі Java».

**Виконав:** Рудаков Богдан, група 124-23-1

Проект зібрано за допомогою Maven, кожна лабораторна робота лежить у власному пакеті
`ua.rudakov.labX` і розроблялась в окремій гілці `LR_X`, яка після завершення зливалась у `master`.

| № | Тема | Пакет / точка входу |
|---|------|---------------------|
| 0 | Hello world | `ua.rudakov.lab0.HelloWorld` |
| 1 | Git та GitHub | цей репозиторій, гілки `LR_X` |
| 2 | Матриця: min, max, середнє арифметичне та геометричне | `ua.rudakov.lab2.MatrixApp` |
| 3 | ООП, модель університету (MVC) | `ua.rudakov.lab3.Run` |
| 4 | JSON (Gson) та JUnit | `ua.rudakov.lab4.Run`, тест `UniversityJsonTest` |
| 5 | JDBC та PostgreSQL | `ua.rudakov.lab5.Run`, скрипт `src/main/resources/database.sql` |
